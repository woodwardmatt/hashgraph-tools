This transaction creates a new HCS topic, where messages can only be submitted by a single key. A new admin key for the topic is also generated.

## Requirements
The following will be required:
- You will need an operator account to pay for the topic creation (account ID and private key) - *update `OPERATOR_ID` and `OPERATOR_KEY` in the .env file with this info*
- You will need the public key that can submit messages - *paste this into generate_topic_with_single_submit.js where it says `<Insert DER-Encoded Public Key>`*
- This code runs under Node JS (and has the `npm run generate-topic-single` script command already configured)

## Getting Started
To use the Generate Topic with Single Submit script:
- Run `npm run generate-topic-single` - the new admin key (and its mnemonic phrase) and the new Topic ID are output when complete
- **Important** - Store the new admin key / phrase safely. It is only ever output in the terminal and not stored anywhere.

## Notes
The following are worth noting:
- The topic's admin key is a new ECDSA key generated by the script. It is needed to update or delete the topic later.
- To allow several keys to submit messages, see [Generate Topic with Threshold Submit Keys](https://github.com/woodwardmatt/hashgraph-tools/wiki/Generate-Topic-with-Threshold-Submit).
