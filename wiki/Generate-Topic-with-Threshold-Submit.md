This transaction creates a new HCS topic, where messages can be submitted by any one of three keys (a 1 of 3 threshold key). A new admin key for the topic is also generated.

## Requirements
The following will be required:
- You will need an operator account to pay for the topic creation (account ID and private key) - *update `OPERATOR_ID` and `OPERATOR_KEY` in the .env file with this info*
- You will need the three public keys that can submit messages - *paste these into generate_topic_with_threshold_submit.js where it says `<Insert DER-Encoded Public Key>`*
- This code runs under Node JS (and has the `npm run generate-topic-threshold` script command already configured)

## Getting Started
To use the Generate Topic with Threshold Submit script:
- Run `npm run generate-topic-threshold` - the new admin key (and its mnemonic phrase) and the new Topic ID are output when complete
- **Important** - Store the new admin key / phrase safely. It is only ever output in the terminal and not stored anywhere.

## Notes
The following are worth noting:
- The topic's admin key is a new ECDSA key generated by the script. It is needed to update or delete the topic later.
- To require more than one signature to submit a message (e.g. 2 of 3), change the number in `new KeyList(multisigPublicKeys, 1)`.
